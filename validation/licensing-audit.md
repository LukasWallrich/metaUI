# Bundled licence audit — 6 October 2026

The code remains GPL-3-or-later. Vendored dmetar code retains its full MIT terms,
Harrer attribution, and a dated modification notice. Original SVG/synthetic
fixtures are GPL-3-or-later. No third-party icons or article PDFs are bundled.

The new Dannheim numeric example is an adaptation of a CC-BY-4.0 article, with
citation, licence link, and changes in both `inst/COPYRIGHTS` and the app About
text. The [publisher](https://www.sjweh.fi/article/4219) explicitly states the
licence. Benchmark inputs were read only; only one 12-row pool is copied. Its
working snapshot lacked `.git`; exact input checksums and member IDs provide
provenance. The benchmark released compilation carries CC0, which does not replace
this retained source attribution.

Existing bundled CSVs contain numeric/categorical coding and bibliographic
identifiers, including Coles study titles; no full abstracts or article prose.
The psymetadata upstream package is GPL-3. Its source documentation points to:

* Aksayli: [OSF jhavp](https://osf.io/jhavp/). Public node API reports CC-BY-4.0,
  year 2018. Attribution and export/adaptation notice added to COPYRIGHTS.
* Coles: [OSF v8kxb](https://osf.io/v8kxb/). Public node API reports MIT, copyright
  Nicholas A. Coles, 2018. Full MIT terms and the holder notice retained.
* Barroso: [OSF 5admx](https://osf.io/5admx/), the upstream pointer. Public node
  API returned 404. Original source redistribution terms are unresolved;
  psymetadata attribution is retained without claiming it settles this question.

This is an evidence record, not a certification of third-party rights. The
unresolved Barroso deposit is a remaining substantial-release gate. No permission
request, author contact, public app deployment, or release occurred.
