# Package index

## Prepare data and build apps

- [`prepare_data()`](https://lukaswallrich.github.io/metaUI/reference/prepare_data.md)
  : Import data from a file and return a data frame
- [`generate_shiny()`](https://lukaswallrich.github.io/metaUI/reference/generate_shiny.md)
  : Generate Shiny app
- [`build_app()`](https://lukaswallrich.github.io/metaUI/reference/build_app.md)
  : Build an app from a declarative JSON configuration

## Customise models and appearance

- [`get_model_tibble()`](https://lukaswallrich.github.io/metaUI/reference/get_model_tibble.md)
  : Get model specifications
- [`app_design()`](https://lukaswallrich.github.io/metaUI/reference/app_design.md)
  : Choose a generated app's design
- [`design_app()`](https://lukaswallrich.github.io/metaUI/reference/design_app.md)
  : Preview and export an app design

## Publish and enrich study metadata

- [`export_static()`](https://lukaswallrich.github.io/metaUI/reference/export_static.md)
  : Export a generated app as a static website (experimental)
- [`fetch_study_metadata()`](https://lukaswallrich.github.io/metaUI/reference/fetch_study_metadata.md)
  : Look up study metadata from DOIs at build time

## Utilities

- [`se.from.p()`](https://lukaswallrich.github.io/metaUI/reference/se.from.p.md)
  : Calculate the standard error from the effect size and p-value
